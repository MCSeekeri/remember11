# Remember11 中文专题站

Remember11 中文专题站是围绕 KID / SDR Project 推出的悬疑视觉小说《Remember11 -the age of infinity-》构建的一站式导航与资料库。本站为新玩家提供避免剧透的平滑游玩指南，同时为通关玩家整理剧情解析、年表、隐藏故事、广播剧以及设定集等资料。

线上站点：<https://remember11.com>

## Features / 功能

- **防剧透流程组织**：根据游玩进度组织侧边栏与层级导航，在搜索和解析专区设置剧透提醒，避免提前泄露核心诡计。
- **剧透遮罩**：全站文本集成 markdown-it-spoiler，支持内联剧透遮罩。
- **本地全文检索**：使用 VitePress 内置的本地搜索，构建时生成索引，无需外部搜索服务。
- **评论交流**：通过 Waline 为各页面提供独立的留言区域。
- **阅读辅助**：支持深色模式、页内大纲、上一篇/下一篇、最后更新时间，以及移动端侧边栏。

## Architecture / 架构

站点由 VitePress 驱动：内容按板块组织为 Markdown 页面，配置集中维护顶部导航与侧边栏，主题层负责布局、灰度样式与 Waline 评论组件；构建时生成本地搜索索引与 sitemap，最终输出纯静态文件。

内容按游玩阶段划分：简介与使用说明、游玩指南、剧情解析（剧透）、游戏资料与资源。新增页面时需要同时登记导航与侧边栏，否则页面不会出现在站内导航中。

## Installation / 安装

```sh
pnpm install
```

## Usage / 使用

启动支持热重载的本地调试服务器：

```sh
pnpm docs:dev
```

构建后如需检查生产环境效果：

```sh
pnpm docs:preview
```

## Testing / 验证

本地构建会同时生成导航关系与搜索索引。提交前运行一次完整构建，检查静态产物中的解析失败、资源断链与排版异常：

```sh
pnpm docs:build
```

## Deployment / 部署

通过 GitHub Actions 接管部署流程。变更合并进 `main` 后，流水线会安装依赖、配置 SSH、执行构建，然后用 rsync 把静态产物同步到服务器的站点目录，完成公网上线。
